How to use External AI Providers in Antigravity Chat
1. Ensure Bridge Proxy is [Running] and Antigravity IDE is [Active].
2. Go to the Antigravity Provider & Models tab and configure your external model (e.g. gemini-4-argon from local port 4982, OpenAI gpt-4o, or Claude claude-3-7-sonnet).
3. In Antigravity IDE, press Ctrl+Shift+P → Developer: Reload Window.
4. In the Chat model picker, select your custom model marked with the [Custom] badge and start chatting!
